# Historical archive

This directory preserves source material and retired experiments removed during the October 2026 cleanup.
It is not compiled, packaged, or loaded by the mod. Keep future production code under `src/`; retain an
archive entry only when its provenance (date and original area) makes it useful for later forensic review.

The V4 texture importer does not consume this directory. Approved artwork must enter through the registry
and the documented V4 import pipeline.
