06 / DEPLOY TO PRISM

Your next session starts here.Deine nächste Session beginnt hier.

Client-side install. No server files required.

Clientseitige Installation. Keine Serverdateien erforderlich.

GAMEMinecraft 1.21.11
LOADERFabric 0.17.3+
RUNTIMEJava 21+
DEPENDENCYFabric API
OPTIONALMod Menu
  1. 01

    Create or choose a Minecraft 1.21.11 Prism instance and install Fabric Loader.

    Erstelle oder wähle eine Prism-Instanz für Minecraft 1.21.11 und installiere Fabric Loader.

  2. 02

    Add Fabric API and use Java 21 for the instance.

    Füge Fabric API hinzu und stelle Java 21 für die Instanz ein.

  3. 03

    Download the JAR from the published release, then add it from Prism → Edit Instance → Mods → Add.

    Lade die JAR aus dem veröffentlichten Release und füge sie über Prism → Instanz bearbeiten → Mods → Hinzufügen hinzu.

  4. 04

    Launch the game and open `/prisons` for the Config GUI.

    Starte das Spiel und öffne `/prisons` für die Config-GUI.
