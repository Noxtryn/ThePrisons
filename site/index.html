Install

  1. Install Fabric Loader 0.17.3 or newer for Minecraft 1.21.11 with Java 21.
  2. Put Fabric API into your mods folder (Mod Menu is optional).
  3. Download theprisons-<version>.jar from the latest release and put it into mods.
  4. Join the server and type /prisons to open the dashboard.

Handy keys and commands

  • F5 + V Tunnel Vision
  • L bandit aim assist
  • K Ore Macro
  • I config
  • /prisons dashboard
  • /prisons price <item> market price
  • /pv storage overlay

FAQ

Is it allowed on Cosmic Prisons?

Read the server rules yourself. Automation and aim assistance can violate them and lead to sanctions.

Where do I put backdrops for Tunnel Vision?

Into config/theprisons/tunnel/ (png or jpg), then pick them on the Tunnel page of the dashboard.

The auction house opens by itself.

Update to the latest version: stray menus of the background scan are closed unseen and the scan waits while the macro runs.
