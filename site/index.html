Cosmic Prisons, your way.Cosmic Prisons, auf deine Art.

A client-side Fabric mod for Minecraft 1.21.11: an animated dashboard, HUD widgets, a market tracker with its own auction house screens, a mining automation with a built-in pathfinder, bandit helpers and Tunnel Vision.

Eine clientseitige Fabric-Mod für Minecraft 1.21.11: animiertes Dashboard, HUD-Widgets, ein Markt-Tracker mit eigenen Auktionshaus-Bildschirmen, eine Mining-Automatik mit eigenem Pathfinder, Banditen-Helfer und Tunnel Vision.

New in 1.2.0: the Bandit Macro - work in progress, only about 2 % done. Neu in 1.2.0: das Bandit-Makro - in Arbeit, erst zu etwa 2 % fertig. It is in the release so you can see where it is going. Expect rough edges and do not leave it running unattended. Es ist im Release, damit ihr seht, wohin die Reise geht. Rechnet mit Ecken und Kanten und lasst es nicht unbeaufsichtigt laufen.

InstallInstallation

  1. Install Fabric Loader 0.17.3 or newer for Minecraft 1.21.11 with Java 21.Installiere den Fabric Loader 0.17.3 oder neuer für Minecraft 1.21.11 mit Java 21.
  2. Put Fabric API into your mods folder (Mod Menu is optional).Lege die Fabric API in deinen mods-Ordner (Mod Menu ist optional).
  3. Download the jar (ThePrisons-<Codename>-v<version>-mc<Minecraft>.jar) from the latest release and put it into mods.Lade die Jar (ThePrisons-<Codename>-v<Version>-mc<Minecraft>.jar) vom neuesten Release und lege sie in mods.
  4. Join the server and type /prisons to open the dashboard.Tritt dem Server bei und tippe /prisons, um das Dashboard zu öffnen.

Handy keys and commandsNützliche Tasten und Befehle

FAQ

Is it allowed on Cosmic Prisons?Ist es auf Cosmic Prisons erlaubt?

Read the server rules yourself. Automation and aim assistance can violate them and lead to sanctions.

Lies die Serverregeln selbst. Automatisierung und Zielhilfen können dagegen verstoßen und zu Strafen führen.

Is the Bandit Macro ready?Ist das Bandit-Makro fertig?

No. It is about 2 % done and mostly untested on the server. Do not leave it running unattended.

Nein. Es ist zu etwa 2 % fertig und größtenteils noch nicht auf dem Server getestet. Lass es nicht unbeaufsichtigt laufen.

Where do I put backdrops for Tunnel Vision?Wohin kommen die Hintergründe für Tunnel Vision?

Into config/theprisons/tunnel/ (png or jpg), then pick them on the Tunnel page of the dashboard.

In config/theprisons/tunnel/ (png oder jpg), dann auf der Tunnel-Seite des Dashboards auswählen.

The auction house opens by itself.Das Auktionshaus öffnet sich von selbst.

Update to the latest version: stray menus of the background scan are closed unseen and the scan waits while the macro runs.

Aktualisiere auf die neueste Version: verirrte Menüs des Hintergrund-Scans werden unsichtbar geschlossen, und der Scan wartet, solange das Makro läuft.
