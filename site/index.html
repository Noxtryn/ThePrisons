ThePrisons is a free, client-side Fabric mod for Cosmic Prisons on Minecraft 1.21.11. A clean dashboard, live session stats, HUD widgets, a storage overlay and customization - configured in one place, installed with one jar.

ThePrisons ist eine kostenlose, clientseitige Fabric-Mod für Cosmic Prisons auf Minecraft 1.21.11. Ein sauberes Dashboard, Live-Session-Stats, HUD-Widgets, eine Lager-Übersicht und Anpassung - an einem Ort eingestellt, mit einer Jar installiert.

InstallInstallation

  1. Install Fabric Loader 0.17.3 or newer for Minecraft 1.21.11 with Java 21.Installiere den Fabric Loader 0.17.3 oder neuer für Minecraft 1.21.11 mit Java 21.
  2. Put Fabric API into your mods folder (Mod Menu is optional).Lege die Fabric API in deinen mods-Ordner (Mod Menu ist optional).
  3. Download the jar (ThePrisons-<Codename>-v<version>-mc<Minecraft>.jar) from the latest release and put it into mods.Lade die Jar (ThePrisons-<Codename>-v<Version>-mc<Minecraft>.jar) vom neuesten Release und lege sie in mods.
  4. Join the server and type /prisons to open the dashboard. That is your first session: pick a design, arrange the HUD, done.Tritt dem Server bei und tippe /prisons, um das Dashboard zu öffnen.

FAQ

Is it allowed on Cosmic Prisons?Ist es auf Cosmic Prisons erlaubt?

Read the server rules yourself. Automation and aim assistance can violate them and lead to sanctions.

Lies die Serverregeln selbst. Automatisierung und Zielhilfen können dagegen verstoßen und zu Strafen führen.

Is the Bandit Macro ready?Ist das Bandit-Makro fertig?

No. It is about 2 % done and mostly untested on the server. Do not leave it running unattended.

Nein. Es ist zu etwa 2 % fertig und größtenteils noch nicht auf dem Server getestet. Lass es nicht unbeaufsichtigt laufen.

Where do I put backdrops for Tunnel Vision?Wohin kommen die Hintergründe für Tunnel Vision?

Into config/theprisons/tunnel/ (png or jpg), then pick them on the Tunnel page of the dashboard.

In config/theprisons/tunnel/ (png oder jpg), dann auf der Tunnel-Seite des Dashboards auswählen.

Is it free?Ist es kostenlos?

Yes. The download is free, needs no account and nothing is sold on this site. The source code is All Rights Reserved (see the licence), so it is free to use, not open source.

Ja. Der Download ist kostenlos, braucht keinen Account, und auf dieser Seite wird nichts verkauft. Der Quellcode ist All Rights Reserved (siehe Lizenz): kostenlos nutzbar, aber kein Open Source.

Is it safe? Can I get banned?Ist es sicher? Kann ich gebannt werden?

We make no promise about that. Some features (Ore Macro, aim assist, recall helper) automate or assist gameplay and can break a server's rules; sanctions are possible. The HUD, dashboard, storage overlay and design features do not automate anything. Read the rules and decide for yourself.

Dazu geben wir kein Versprechen. Einige Funktionen (Ore Macro, Zielhilfe, Rückruf-Helfer) automatisieren oder unterstützen das Spiel und können gegen Serverregeln verstoßen; Strafen sind möglich. HUD, Dashboard, Lager-Übersicht und Design automatisieren nichts. Lies die Regeln und entscheide selbst.

Does it work in singleplayer or on other servers?Geht es im Einzelspieler oder auf anderen Servern?

It is built for Cosmic Prisons; many features read that server's menus, chat and sidebar. Elsewhere only the generic parts (dashboard, design, Tunnel Vision) make sense.

Sie ist für Cosmic Prisons gebaut; viele Funktionen lesen Menüs, Chat und Sidebar dieses Servers. Anderswo sind nur die allgemeinen Teile (Dashboard, Design, Tunnel Vision) sinnvoll.

Why is the auction house / market not in the mod?Warum fehlt das Auktionshaus / der Markt?

The market module is switched off in release builds until it has been reviewed (too many bugs). It will come back when it is stable.

Das Markt-Modul ist in Release-Builds abgeschaltet, bis es überprüft ist (zu viele Fehler). Es kommt zurück, sobald es stabil ist.

Where can I get help?Wo bekomme ich Hilfe?

See Support: the Discord (if linked) or a GitHub issue. Please include your version and logs/latest.log.

Siehe Support: der Discord (falls verlinkt) oder ein GitHub-Issue. Bitte Version und logs/latest.log beilegen.
