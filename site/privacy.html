Privacy / Datenschutz

English

  • This site uses no cookies and no advertising or social-media trackers. Fonts and scripts are served from this site.
  • Your language choice is stored in your browser (localStorage) only.
  • The page asks the public GitHub API for the latest release (version, download link, notes, download count). GitHub sees that request like any other visit to its API.
  • Optional statistics: if the site owner enables it, anonymous, cookie-free counts of page views and of clicks on Download, Install, GitHub and Discord are collected with GoatCounter (no personal profile, no IP storage by the site, Do Not Track is respected). It is off unless config.json names a GoatCounter site.
  • The mod itself sends no analytics. Its update checker asks the GitHub releases API (and Modrinth) for the newest version.

Deutsch

  • Diese Seite nutzt keine Cookies und keine Werbe- oder Social-Media-Tracker. Schriften und Skripte kommen von dieser Seite.
  • Deine Sprachwahl wird nur in deinem Browser gespeichert (localStorage).
  • Die Seite fragt die öffentliche GitHub-API nach dem neuesten Release (Version, Download-Link, Notizen, Download-Zahl). GitHub sieht diese Anfrage wie jeden Aufruf seiner API.
  • Optionale Statistik: Wenn der Betreiber sie einschaltet, werden anonyme, cookiefreie Zählungen von Seitenaufrufen und Klicks auf Download, Installation, GitHub und Discord mit GoatCounter erhoben (kein Personenprofil, Do Not Track wird beachtet). Ohne GoatCounter-Eintrag in config.json ist sie aus.
  • Die Mod selbst sendet keine Analyse-Daten. Der Update-Check fragt die GitHub-Releases-API (und Modrinth) nach der neuesten Version.
