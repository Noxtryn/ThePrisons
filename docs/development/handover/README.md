# Development handover

This directory is the factual handover point for the temporary Codex integration work.
Read `CURRENT_STATE.md`, then `ARCHITECTURE.md`, `FEATURE_STATUS.md`, and the task-specific
notes before changing an active subsystem. Every completed commit must be added to
`CHANGES_BY_CODEX.md` and its verification to `TEST_RESULTS.md`.

The V4 art importer is intentionally offline and fail-closed. Its operational guide is
`TEXTURE_PIPELINE.md`; artwork must not be copied into the built-in HD V2 pack manually.
