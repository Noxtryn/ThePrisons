# Productive Config UI rework (2026-10-08)

## Scope and actual call path

This change deliberately does **not** add a second config renderer.

`ThePrisonsClient.dashboard()` creates `DashboardScreen`; selecting a module invokes that screen's
`openClassic` callback and creates `io.theprisons.gui.click.ClickGuiScreen`. `ClickGuiScreen` is the
production editor which renders the category navigation, module cards, setting controls, dropdowns, keybind
capture, text editing, scrolling and Save/Load/Reset. Its `close()` persists through `ConfigStore`.

The rework changes that class directly:

- responsive gunmetal command-center shell, header and metallic accents;
- usable Overview, Mining, Bandit, Market, Item Tools, HUD, PvP & Safety and Settings filters;
- Market and Item Tools map to the existing modules rather than invented placeholders;
- Overview exposes the selected module's real settings; it is not a read-only mockup;
- expanded cards and panels with visible enabled/error state;
- GUI-scale-aware sidebar: all categories remain clickable at scale 3 and the optional macro status is suppressed
  before it can overlap the footer.

## Rarity base

`ItemRarity` remains the single presentation palette used by tooltip frames, inventory cards and market views.
Godly now uses the pink energy colour `#FF8DEB`; Executive uses the requested silver `#C7CED8` (the surrounding
frame/background supplies the black gunmetal treatment). No item identity or market value was changed.

the actual `ClickGuiScreen` in a Fabric client at

the same productive renderer and `./gradlew test build --no-daemon` passes. A fresh screenshot after the final
width tuning, plus an interactive live-Prism check through Right Shift -> module selection, remains **NOT YET
MANUALLY VERIFIED**. Do not describe that final visual tuning as live-server verified until that check is made.

## Market renderer follow-up

The actual AH/EE interception opens `MarketScreen`, not the generic `AhOverlayRender` alone. `MarketScreen` now
adds a rarity outline only when `PrisonsItems.info(stack)` confirms a tier and expands its own hover with the
unmodified server item lore followed by listing price, observed low/source, data age, percentage comparison and
the current observed EE conversion. The EE footer derives 100k and 1m purchase costs from the same verified
`PriceBook.moneyPerEnergy()` value; no synthetic balance or rate is introduced.

`./gradlew runClientGameTest -Pmarket --no-daemon` passed. Captures `0007_market_2_ah.png` and
`0008_market_3_ee.png` are real client renders using synthetic test offers; they validate layout and the data
flow, but do **not** validate live Cosmic seller data. `./gradlew test build --no-daemon` also passed afterward.
