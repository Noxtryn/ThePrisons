# Marketing kit

All material uses only features that are **on in release builds** (`FeatureProfile.ON` + `FREE`). The market module
(auction house, `/ee`, shop overlays, item list) is **off** - do not feature it until it is re-enabled.

Rules for every text, image and clip: transparent, no safety or detection claims of any kind, mention that
automation can break server rules, no private information in screenshots, no unsolicited DMs, no fake accounts.
